# Grievance intake (sample)

Sample corpus for demo — replace with official documents.

## Who can file

A student or a faculty member of an affiliated institution can file a complaint in the portal. A student whose
affiliation is not yet verified can still file; the complaint is held at AICTE triage and is not forwarded until the
affiliation is checked.

## What a complaint should contain

The complaint states the institution, the category (financial, ragging, academic, infrastructure or other), a clear
description of the issue, and any supporting documents. A description shorter than the minimum length is not accepted.

## Acknowledgement

After filing, the complainant receives a case reference. The reference is the only identifier needed to check
progress in the portal.

## Triage

A triage officer reads each new case and decides whether it is in scope, which bureau handles it, and whether it is
urgent. Out-of-scope matters are told so in writing, with the reason.
